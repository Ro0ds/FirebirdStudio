# Firebird Studio 0.2.1

This release adds database creation and managed embedded Firebird engines to the Windows x64 desktop app.

## What's new

- Create a database on the Firebird instance used by the active connection and optionally save a separate connection profile for it.
- Create or open a local database with embedded Firebird 2.5.9, 3.0.14, 4.0.7, or 5.0.4. The app downloads the selected engine on demand. To prepare all versions ahead of time, open **File → Settings → Embedded Firebird** and select **Download all engines**.
- Select either `.fdb` or `.gdb` in the database file pickers. New local databases default to `.fdb`.
- Use the same Windows TLS 1.2 configuration for engine downloads and application updates.

See the [database creation and engine download guide](../architecture/CONNECTION-MANAGER.md#create-a-database) for details.

## Validation

The maintainer reported successful manual tests with Firebird 4.0 and 5.0. The [compatibility matrix](../architecture/FIREBIRD-COMPATIBILITY.md) tracks the remaining automated integration coverage.

The Windows x64 release workflow produces two portable ZIPs, one requiring the .NET 10 Desktop Runtime and one including the runtime. It also produces the SHA-256 checksum list and updater manifest. [Windows packaging guide](WINDOWS.md)
