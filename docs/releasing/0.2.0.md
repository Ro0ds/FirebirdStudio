# Firebird Studio 0.2.0

## What's new

- Redesigned desktop workspace with an application icon, refined light and dark themes, and readable SQL selection in both the editor and the DDL inspector.
- Two connection list modes and a database object explorer with search, type filtering, category ordering, and incremental loading.
- Query history that can dock alongside the editor or open in a tab. Preview a statement and restore it to the editor.
- Results with sortable columns, first and last row navigation, and row copying. Messages show severity, timestamps, and copyable diagnostic details.
- Settings for the execution shortcut and per-theme colors, including a visual palette, a spectrum, and contrast validation. `F9` is the default shortcut.
- English by default and Brazilian Portuguese as the fallback. Choose the interface language in Settings and restart to apply it.

## Windows x64 validation

The candidate was built from `development` at `5b37600` after PR #29, with `VERSION` set to `0.2.0`.

| Check | Result |
|---|---|
| Release build and automated suite | 96 tests passed, and the repository structure and localization checks passed. |
| Framework-dependent and self-contained ZIPs | Both extracted executables opened the 0.2.0 main window. Both ZIPs included the updater and matched their manifest size and SHA-256. |
| Firebird 5.0.4 embedded with a disposable database | Connected and disconnected, switched between active and offline profiles, loaded two pages of metadata, searched by name, and checked formatted table, view, and trigger DDL. |
| Query workflow | Executed SQL with a typed named parameter, sorted results in both directions, moved to the first and last rows, and checked the copied row payload. Restored SQL from history and verified error and success transitions between Messages and Results. Cancelled a query waiting for the session. |
| Preferences and editor recovery | Loaded settings and editor tabs in the previous format. Changed the connection list mode, theme, accent, execution shortcut, and interface language. Reopened the application with an isolated profile and verified the saved editor text, theme, shortcut, language, and query history. |

The database smoke run covered Firebird 5.0.4 in embedded mode. Remote connections and the other targeted Firebird versions remain part of the [compatibility matrix](../architecture/FIREBIRD-COMPATIBILITY.md). See the [Windows packaging guide](WINDOWS.md) for package requirements.
